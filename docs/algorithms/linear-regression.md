# Shipping Cost Estimate

## What it does

This model estimates how much it might cost to ship a parcel. It learns from past shipments and their actual shipping costs.

## What information it uses

- How far the parcel travels
- How much it weighs
- How many stops are on the route
- The fuel price

## What you see on the screen

On the **Quote** page, enter the shipment details to see an estimated price in Philippine pesos. You will also see a percentage that summarizes how far off the model was, on average, when tested on past examples it had not trained on.

The page also shows a delivery-time estimate from a different model. That time is not part of the cost calculation.

## Who might use it

A sender can check an estimated cost before sending a parcel. A company employee can use it as a starting point when preparing a quote.

## Keep in mind

The estimate is not a final price or a promise. The displayed accuracy percentage describes the model's past test results; it does not say exactly how wrong this particular estimate might be.
