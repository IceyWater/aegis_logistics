# Customer-Message Triage

## What it does

This model reads a customer message and suggests what the customer may need help with.

## What it can suggest

- Damaged parcel
- Address problem
- Tracking request
- Missing parcel
- Reschedule request
- Shipping fee

## What you see on the screen

On the **Triage** page, paste a message to see the three most likely categories. Each category has a bar showing how strongly the model favors it. The page also suggests a department based on the top category.

## Who might use it

A customer can see how their message might be understood. A support employee can use the suggestion as a starting point when deciding which team should review it.

## Keep in mind

The suggestion is not sent to a real support queue. A message may describe more than one problem, use unfamiliar words, or be unclear. A support employee should confirm what the customer needs.

The displayed 40% faster response figure is a company goal, not a result proven by this model.
